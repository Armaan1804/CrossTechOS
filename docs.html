1. PostgreSQL DDL Schemas

The core schema revolves around three primary entities: organizations, sites, and the immutable wallet_transactions double-entry ledger table.

-- Transaction type enum CREATE TYPE txn_type_enum AS ENUM ( 'SANCTION', -- Capital injection from Org Wallet 'EXPENSE', -- Field petty cash debit 'ADJUSTMENT', -- Formal countervailing audit entry 'REVERSAL' -- Cryptographically signed reversal ); -- Append-only Double-Entry Ledger CREATE TABLE wallet_transactions ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), org_id UUID NOT NULL REFERENCES organizations(id), site_id UUID NOT NULL REFERENCES sites(id), txn_type txn_type_enum NOT NULL, amount_inr NUMERIC(14,2) NOT NULL CHECK (amount_inr > 0), balance_after NUMERIC(14,2) NOT NULL, category VARCHAR(100) NOT NULL, receipt_r2_path TEXT, created_by UUID NOT NULL REFERENCES auth.users(id), created_at TIMESTAMPTZ DEFAULT now() ); CREATE INDEX idx_wallet_txns_org_site ON wallet_transactions(org_id, site_id, created_at DESC);

2. Atomic Transaction Execution Procedure

Balance modifications strictly pass through process_wallet_transaction() to enforce atomic row locks and verify controlled overdraft floors.

CREATE OR REPLACE FUNCTION process_wallet_transaction( p_org_id UUID, p_site_id UUID, p_type txn_type_enum, p_amount NUMERIC, p_category VARCHAR, p_receipt_path TEXT ) RETURNS UUID AS $$ DECLARE v_current_bal NUMERIC; v_overdraft_floor NUMERIC; v_new_bal NUMERIC; v_txn_id UUID; BEGIN -- Acquire exclusive row lock on site record SELECT current_balance, overdraft_limit INTO v_current_bal, v_overdraft_floor FROM sites WHERE id = p_site_id FOR UPDATE; IF p_type = 'EXPENSE' THEN v_new_bal := v_current_bal - p_amount; IF v_new_bal < -v_overdraft_floor THEN RAISE EXCEPTION 'Site overdraft floor reached. Transaction rejected.'; END IF; ELSE v_new_bal := v_current_bal + p_amount; END IF; -- Update cached site balance UPDATE sites SET current_balance = v_new_bal WHERE id = p_site_id; -- Insert immutable double-entry record INSERT INTO wallet_transactions (org_id, site_id, txn_type, amount_inr, balance_after, category, receipt_r2_path, created_by) VALUES (p_org_id, p_site_id, p_type, p_amount, v_new_bal, p_category, p_receipt_path, auth.uid()) RETURNING id INTO v_txn_id; RETURN v_txn_id; END; $$ LANGUAGE plpgsql;

3. Offline Dexie.js IndexedDB Schema

On-device queue that absorbs subterranean field entries when 4G connectivity is unavailable.

import Dexie from 'dexie'; export class BuildLedgerOfflineDB extends Dexie { constructor() { super('BuildLedgerDB'); this.version(1).stores({ pending_transactions: '++local_id, client_uuid, site_id, sync_status, created_at', offline_receipts: 'client_uuid, blob, mime_type' }); } }

4. Cloudflare R2 Presigned S3 Storage API

Clients request presigned upload URLs and push WebP blobs directly to Cloudflare R2, bypassing edge API compute servers to maintain zero egress bandwidth overhead.
